# Hello From a Tiny MDX Blog

![A simple blog card image](/images/twitter-card.png)

This is the first post in this minimal MDX blog. It is not a Tailwind starter and it is not a Next.js template. It is just content, a tiny router, and a Vite build that turns MDX into React components.

The shape is deliberately small: posts live in `content/posts`, the index lists them, and `/blog/:slug` renders the matching file.
