# Quiet Routing

![A mountain range from the Tailwind starter template](/images/canada/mountains.jpg)

The blog only needs two routes:

- `/` for the post list
- `/blog/:slug` for a single post

That makes `wouter` a comfortable fit. It keeps the URL honest without asking the blog to become a larger application framework.
